## 🎯 Objetivo

A proposta é oferecer monitoramento simples, acessível e profissional para:

# Diferenciais

## Simplicidade

O InfraWatch não tenta competir com soluções enterprise complexas.

**A proposta é:**

* configuração rápida
* painel intuitivo
* baixo custo
* fácil manutenção

---

## Arquitetura Gratuita

Toda a infraestrutura inicial utiliza serviços gratuitos permanentes.

---

## Foco em Pequenas Empresas

**A maioria das ferramentas de observabilidade possui:**

* custo elevado
* configuração complexa
* excesso de funcionalidades

O InfraWatch busca resolver o essencial.
